# 天猛星与逐飞核心板关键差异

| 项目 | 逐飞核心板默认 | 天猛星 | 处理 |
|---|---|---|---|
| MCU | MSPM0G3507SPMR | MSPM0G3507SPMR | 直接兼容 |
| HFXT | PA5/PA6，40 MHz | PA5/PA6，40 MHz | 保留 |
| LFXT | PA3/PA4，32.768 kHz | PA3/PA4，32.768 kHz | 保留 |
| 调试 UART | PA10/PA11 | PA10/PA11，板载 CH340E | 保留 |
| BSL | PA18 | PA18 | 保留 |
| SWD | PA19/PA20 | PA19/PA20 | 保留 |
| 用户 LED | PA14 | PB22 | 已修改 |
| 用户按键 | 示例外接引脚 | PB21 | 已新增板级定义 |
| 板载 SPI Flash | 无 | PB6～PB9 | CS 默认拉高；PWM 示例避开 PB9 |
| 物理排针 | 逐飞 60 位布局 | 天猛星 80 位布局 | 不可直接互插 |

## 说明

逐飞底层 GPIO、UART、ADC、PWM 等驱动以 MSPM0G3507 引脚复用表为依据，绝大多数驱动本身不绑定核心板。真正的板级绑定主要集中在：

- 上电安全引脚；
- 板载 LED、按键；
- 默认调试串口；
- 示例工程选用的具体引脚；
- 板载 Flash 等固定外设冲突。

因此本次不是重写驱动，而是解除逐飞核心板的板级假设，并补充天猛星板级资源定义。
