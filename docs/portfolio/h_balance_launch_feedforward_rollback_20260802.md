# H 题发车前馈试验与回退决策记录

> 日期：2026-08-02
> 性质：阶段性工程决策记录，不代表当前主线参数或最终赛场结论。

## 目标与约束

当车辆启动冲击导致钢球出现明显位移时，只试验一次性、有限时长的前馈补偿。试验不得改变正常建零、零点、PID 参数或其他按键任务；结果不理想时必须能完整回退到试验前稳定基线。

## 当时的试验方案

- 触发源为真实发车事件，而不是视觉噪声或普通任务切换。
- 仅在首次建零完成、任务空闲且没有远程目标时生效。
- 前馈采用有限幅值和有限时间窗：正向 3.5°，120 ms 上升、180 ms 保持、420 ms 退出。
- 不清空积分项，不切换 PID 组；串口增加 `LFF` 与 `LACT` 字段用于区分“配置值”和“当前是否激活”。
- LED 验收保持在平台层，不把它耦合进平衡 PID 状态机。

## 回退策略

试验前冻结控制配置、平衡控制头文件、平衡控制实现和应用入口四个核心文件。若实物响应不满足预期，则恢复这四个文件并重新编译验证，不把失败试验继续叠加到稳定基线上。

## 证据边界

该方案体现的是一次受控试验和回退设计。离线回放与仿真只能用于筛选参数，不能替代真实车辆冲击、机械摩擦、执行器延迟和安全边界下的重复实测。当前主线状态以根目录 `README.md`、`docs/verified_wiring_and_bringup_log.md` 和源代码配置为准。
