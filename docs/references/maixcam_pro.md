# MaixCAM Pro 资料摘要

## 原始资料

- 原始 MaixCAM 资料不纳入仓库；请从官方页面或队伍共享存储获取。
- 官方资料：[MaixCAM Pro 页面](https://wiki.sipeed.com/hardware/zh/maixcam/maixcam_pro.html)、[MaixPy UART 文档](https://wiki.sipeed.com/maixpy/doc/en/peripheral/uart.html)。

原始包适合在需要刷机、查扩展接口或复现官方示例时使用；日常视觉联调不需要整包复制到主控工程。

## 推荐阅读顺序

1. 先看官方板卡页，确认供电、存储卡、摄像头与网络的基本状态。
2. 再看 UART 文档，确认程序打开的是自定义串口而不是系统日志串口。
3. 最后按 `docs/maixcam_protocol.md` 实现本项目的发送帧，不使用历史的 `$V,...#` ASCII 格式作为云台正式协议。

## 本项目只需掌握

- MaixCAM Pro 外置，不焊接到主控底板。
- 使用 MaixCAM 的 `UART1`：`A19` 为 TX、`A18` 为 RX，IO 电平为 3.3 V TTL。
- 接线：`A19 TX -> MSPM0 PA9 RX`，`A18 RX <- MSPM0 PA8 TX`，两端必须共地。
- 发送给 MSPM0 的二进制帧格式、字节序和超时规则以 `docs/maixcam_protocol.md` 为准。
- 调试起点：`firmware/maixcam/main.py` 先发送假数据，再替换为真实视觉结果。

## 发送职责与数据约束

MaixCAM 只输出“当前视觉结果”，不直接决定电机的目标位置。正式帧有四类：

| 状态 | 发送内容 | 主控预期行为 |
| --- | --- | --- |
| 发现目标 | yaw、pitch、confidence | 更新云台目标 |
| 目标丢失 | 无数据 | 停止继续追踪旧目标 |
| 心跳 | 运行时间、序号 | 仅用于判断链路存活 |
| 错误 | 错误码 | 主控丢弃旧目标，等待恢复 |

- yaw、pitch 是相对画面中心的误差，单位为 `0.01 deg`，并采用小端序。
- 推荐每 50 ms 发送一帧发现/丢失状态；500 ms 没有合法目标时，MSPM0 停止云台。
- 先固定相机安装方向，再明确 yaw/pitch 正负号；不要在视觉算法和云台层分别反向补偿。

## 首次联调清单

1. 断开电机，只连接 MaixCAM、天猛星和共地线。
2. 运行 `main.py` 假数据，使用 UART0 日志确认 MSPM0 能收到合法帧。
3. 依次验证目标发现、目标丢失、错误校验和超时停止。
4. 替换为真实检测结果后，检查角度正负、置信度范围与实际帧率。
5. 最后才接入 X42S，并从低速、小角度开始测试。
