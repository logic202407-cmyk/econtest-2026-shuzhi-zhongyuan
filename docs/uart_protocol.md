# UART 协议

MaixCAM Pro 作为发送端，STM32F407 / MSPM0G3507 作为接收端。

## 数据帧

```text
$V,mode,cx,cy,w,h,D,x,angle,conf#
```

示例：

```text
$V,1,320,240,80,80,150.0,8.0,0.0,0.99#
```

## 字段说明

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `$` | char | 帧头 |
| `V` | char | 视觉数据帧类型 |
| `mode` | int | 当前识别/任务模式 |
| `cx` | int/float | 目标中心 x 坐标 |
| `cy` | int/float | 目标中心 y 坐标 |
| `w` | int/float | 目标框宽度 |
| `h` | int/float | 目标框高度 |
| `D` | float | 距离或估算深度，单位按任务约定 |
| `x` | float | 横向偏移或任务相关位置量 |
| `angle` | float | 目标角度 |
| `conf` | float | 置信度，建议范围 0.00-1.00 |
| `#` | char | 帧尾 |

## 推荐串口参数

| 参数 | 建议值 |
| --- | --- |
| 波特率 | 115200 |
| 数据位 | 8 |
| 校验位 | None |
| 停止位 | 1 |
| 电平 | 3.3 V TTL |

## 接收端解析建议

1. 以 `$` 开始缓存。
2. 收到 `#` 后认为一帧结束。
3. 检查是否以 `$V,` 开头。
4. 按逗号分割字段，确认字段数量为 10 个数据字段。
5. 将数值转换为对应类型，转换失败则丢弃该帧。

## 后续可扩展

- 增加校验和字段，例如 `$V,...,checksum#`。
- 增加心跳帧，例如 `$H,tick#`。
- 增加主控到 MaixCAM 的模式切换命令。
