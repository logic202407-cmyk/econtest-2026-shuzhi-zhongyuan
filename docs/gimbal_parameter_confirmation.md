# 自制云台参数确认表

适用对象：适配 42 系列步进电机的 3D 打印自制双轴云台，主控为天猛星 MSPM0G3507，执行器为两台 X42S 第二代闭环步进电机。

本云台没有可直接引用的厂家机械参数。未完成实物标定前，不得扩大运动范围、速度或电流。

## 2. 当前实测结果

2026-07-23 使用 USB-RS485 对两台电机并联测试：

| 项目 | 命令 | 返回 | 结论 |
| --- | --- | --- | --- |
| 读 Pitch 位置 | `01 36 6B` | `01 36 ... 6B` | ID1 在线。 |
| 读 Yaw 位置 | `02 36 6B` | `02 36 ... 6B` | ID2 在线。 |
| Pitch 小角度位置命令 | `01 FD ... 6B` | `01 FD 02 6B` | 可控。 |
| Yaw 小角度位置命令 | `02 FD ... 6B` | `02 FD 02 6B` | 可控。 |
| Pitch 停止 | `01 FE 98 00 6B` | `01 FE 02 6B` | 可停。 |
| Yaw 停止 | `02 FE 98 00 6B` | `02 FE 02 6B` | 可停。 |

已验证约 20 度总范围内的双轴低速循环运动。测试命令采用 Emm 位置模式，速度约 `20 RPM`，加速度档位约 `5`。

### 天猛星实测接线与按键联调

当前使用的是自动方向 TTL-RS485 小模块。模块丝印按主控侧命名，故接线必须按下表，不要按常见“交叉 TX/RX”经验再交换一次：

| 天猛星 | TTL-RS485 小模块 | 说明 |
| --- | --- | --- |
| `B12` / UART3 TX | `TXD` | 主控发送侧 |
| `B13` / UART3 RX | `RXD` | 主控接收侧 |
| `3.3V` | `VCC` | 不接 5V |
| `GND` | `GND` | 必须与电机电源负极共地 |
| RS485 `A+` | 转接板 `R/A/H` | 总线 A |
| RS485 `B-` | 转接板 `T/B/L` | 总线 B |

转接板 `GND`、24V 电源负极、TTL-RS485 模块 GND、天猛星 GND 必须连通。`B14` 不接当前自动方向模块，只为以后手动 DE/RE 模块保留。

当前 B21 联调固件的动作序列是：复位后第一次按键使能 ID1/ID2；第二次发送两轴 `+20 deg` 相对位置命令；第三次发送两轴 `-20 deg` 相对位置命令；第四次停止两轴。这里必须使用 `Rel=1` 相对位置帧，不能替代为绝对位置帧。

## 4. 当前软件保护

工程默认仍保持：

```c
GIMBAL_MOTION_ENABLED == 0U
```

此时自动视觉闭环不会输出位置运动命令。只有完成方向、零点和软限位确认后，才允许改成 `1U` 做小范围自动跟踪。

当前 `application/config/app_config.h` 中的 X42S 默认参数为低速联调起点：

```c
X42S_PITCH_MOTOR_ID = 1
X42S_YAW_MOTOR_ID   = 2
X42S_DEFAULT_SPEED_0P1_RPM_CFG = 200
X42S_DEFAULT_ACC_RPM_S_CONFIG  = 50
```

## 5. 后续标定顺序

1. 断开视觉闭环，只用 USB-RS485 或主控测试单轴小角度相对运动。
2. 分别确认 Pitch 和 Yaw 的正方向。
3. 建立机械零点，并记录上电后是否需要回零。
4. 缓慢移动到安全边界，记录软限位。
5. 安装 MaixCAM、电缆和全部负载后，重新检查干涉、抖动、温升和电流。
6. 最后接入真实视觉数据，先验证 500 ms 失目标停止，再扩大跟踪范围。
