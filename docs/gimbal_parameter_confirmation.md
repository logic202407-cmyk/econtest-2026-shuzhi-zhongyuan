# 自制云台参数确认表

适用对象：适配 42 系列步进电机的 3D 打印自制双轴云台，主控为天猛星
MSPM0G3507，执行器为 X42S 闭环步进电机。

本云台没有可直接引用的厂家机械参数。未完成实物标定前，下面标为“待确认”
的项目不得由软件猜测，也不得据此放大运动范围、速度或电流。

当前 `app_config.h` 中的 `GIMBAL_YAW_*`、`GIMBAL_PITCH_*` 和 X42S
速度/加速度宏仅为保守的软件联调起点，并非机械规格。完成本表后才能替换为
实测值。

失能命令，云台控制层拒绝输出位置命令。首次解锁流程见
`docs/first_board_bringup.md`。

## 3. 硬件到位后的标定顺序

1. 断开云台负载或保证周围无干涉，确认 XDS110 的 SWD 连线、UART0 调试输出和 RS485 A/B 接线。
2. 每次只连接一个 X42S，以低速、小角度位置命令测试，例如 `+5 deg` 与 `-5 deg`。
3. 确认该轴电机 ID 与实际机械轴，记录正负方向；若方向相反，先处理软件符号，再继续测试。
4. 缓慢移动至两个方向的机械安全边界，在硬限位前预留余量，填入软限位最小值和最大值。
5. 回到统一的机械零点，记录零点建立方式。没有可靠零点时，不启用绝对角度任务。
6. 安装 MaixCAM、电缆和全部负载后，重新检查干涉、抖动、温升和电流，再提高速度与加速度。
7. 最后才接入真实视觉数据，先验证 500 ms 目标丢失停止，再扩大跟踪范围。

## 4. 无硬件期间可完成的检查

- 运行 `tests/run_host_tests.ps1`，验证视觉帧、X42S 指令帧、超时停止和软件限位逻辑。
- 使用 `tools/serial_debug/serial_debug.py` 生成 MaixCAM 与 X42S 的黄金字节序列，不连接串口时默认仅输出十六进制。
- 用 Keil 编译生成的天猛星工程，确认应用层、平台层和逐飞底层的引用路径完整。
- 核对本表与 `application/config/app_config.h`；未标定项目保持“待确认”，不要写入臆测数值。
