## 当前禁用或不可同时启用的功能

| 资源 | 状态 | 原因 |
| --- | --- | --- |
| TJC 串口屏 UART2 | 禁用 | 原计划 TX=PB15、RX=PB16；PB15 现为右轮电机 PWM，不能同时使用 |
| IPS200PRO | 禁用 | 与灰度传感器和预留 ADC 引脚冲突，且实物屏幕异常 |
| 陀螺仪 | 禁用 | 原接法与 UART0 或 OLED 引脚冲突，传感器型号和总线尚未重新确认 |
| 旧双轴云台自动跟踪 | 禁用 | `GIMBAL_MOTION_ENABLED == 0U`；不参与 H 题平衡控制 |
| H 题 X42S 平衡闭环 | K1 显式使能 | 默认最大相对水平零点 `±5°`；未按 K1 不运动 |

## 接线前必须确认

1. 右电机控制线必须为 `PB15` 和 `PA27`，不能再接回 `PA26`。
2. 右轮编码器必须为 `PA24` 和 `PA17`，不能再接回 `PA25`。
3. K1/K2 已在扩展板内部对应 `PA26/PA25`，按下接地，无需额外飞线。
4. X42S 使用自动方向 TTL-RS485 时：`PB12 -> TXD`、`PB13 -> RXD`，并与 24 V 电源负极共地；PB14 不接。
5. H题升降仅使用一台 X42S，当前控制器使用 ID1；已确认 `CW/角度增加=抬高`、
   `CCW/角度减小=下降`。首次按 K1 前仍必须手动调平，控制器会把当时编码器位置锁存
   为水平零点。闭环说明见 [H题小球平衡视觉与 X42S 闭环](h_balance_closed_loop.md)。
