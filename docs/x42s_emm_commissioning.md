# X42S Emm 固件实测记录

日期：2026-07-23

## 结论

当前手头这批 X42S 第二代闭环步进电机使用的是 **Emm 固件自由协议**，不是此前仓库默认假设的 X 固件自由协议。

本地资料目录中也有提示：

```text
默认是Emm固件，软硬件完全兼容上一代X42版本.txt
```

因此主控和 PC 调试工具统一按：

- 物理层：RS485
- 串口：115200, 8N1
- 协议：Emm 固件自由协议
- 校验：固定 `0x6B`

## 接线

USB-RS485 与单个 X42S：

| USB-RS485 | X42S |
| --- | --- |
| A+ | R/A/H |
| B- | T/B/L |
| GND | Gnd |

电源：

| 电源 | X42S |
| --- | --- |
| 24V+ | V+ |
| 24V- | Gnd |

必须共地：`24V-`、`X42S Gnd`、`USB-RS485 GND` 接在一起。

## 已验证命令

以下命令均在 `COM6`、115200 8N1 下实测通过。

| 功能 | 发送 | 实测返回示例 |
| --- | --- | --- |
| 使能 | `01 F3 AB 01 00 6B` | `01 F3 02 6B` |
| 失能 | `01 F3 AB 00 00 6B` | `01 F3 02 6B` |
| 停止 | `01 FE 98 00 6B` | `01 FE 02 6B` |
| 读实时速度 | `01 35 6B` | `01 35 00 00 00 6B` |
| 读实时位置 | `01 36 6B` | `01 36 00 00 00 40 0B 6B` |
| 速度模式 +30 RPM | `01 F6 00 00 1E 05 00 6B` | `01 F6 02 6B` |
| 相对位置 +800 clk | `01 FD 00 00 1E 05 00 00 03 20 01 00 6B` | `01 FD 02 6B` |

## Emm 帧格式

### 速度模式

```text
Addr F6 Dir SpeedH SpeedL Acc Sync 6B
```

- `Dir=0`：一个方向
- `Dir=1`：反方向
- `Speed`：RPM，16 位大端
- `Acc`：加速度参数，8 位
- `Sync`：多机同步标志，单机调试先用 `00`

### 位置模式

```text
Addr FD Dir SpeedH SpeedL Acc Clk3 Clk2 Clk1 Clk0 Rel Sync 6B
```

- `Speed`：RPM，16 位大端
- `Acc`：加速度参数，8 位
- `Clk`：目标脉冲数，32 位大端
- `Rel=1`：相对运动
- `Rel=0`：绝对运动

实测 `800 clk` 约等于 `90 deg`，按 `3200 clk/rev` 换算。

## 仓库修改

应用层仍保持角度接口：

```c
X42S_SetPosition(id, position_0p1deg);
X42S_SetSpeed(id, speed_0p1rpm);
```

底层驱动内部完成换算：

- 位置：`0.1 deg` -> `clk`
- 速度：`0.1 RPM` -> `RPM`

运动仍受 `GIMBAL_MOTION_ENABLED` 保护。没有完成云台 ID、方向、零点、软限位确认前，不要打开自动云台运动。

## 双轴云台实测

2026-07-23 已完成两台 X42S 并联到同一条 RS485 总线的低速测试。

| 轴 | 电机 ID | 机械位置 | 职责 |
| --- | --- | --- | --- |
| Pitch | `1` | 上方电机 | 控制摄像头俯仰角。 |
| Yaw | `2` | 底部电机 | 控制云台平面内旋转角。 |

双轴测试命令均返回成功：

```text
01 FD ... 6B -> 01 FD 02 6B
02 FD ... 6B -> 02 FD 02 6B
01 FE 98 00 6B -> 01 FE 02 6B
02 FE 98 00 6B -> 02 FE 02 6B
```

低速联调建议继续使用：

- 速度：`20 RPM`
- 加速度档位：`5`
- 单次测试范围：先控制在约 `10 deg`
- 总循环范围：先控制在约 `20 deg`

不要使用广播地址发送运动命令。双轴同时运动时，先分别确认 `01 36 6B` 与 `02 36 6B` 都有返回，再发送运动命令。
